## About Me

Hi, I’m Omesh — a student at IIT Patna who enjoys turning ideas into systems that actually work.

I like building scalable full-stack applications, real-time data systems, and AI-powered platforms. Over the last few years, I’ve worked on projects ranging from revamping institutional-scale web infrastructure to experimenting with machine learning, distributed systems, vector databases, and multi-modal AI.

I enjoy the process of building:
- breaking things
- fixing them
- optimizing them
- rebuilding them better

Most of my work sits at the intersection of:
- Full Stack Engineering
- Machine Learning
- Distributed Systems
- DevOps
- Real-Time Data Infrastructure

I actively participate in hackathons, explore open-source projects, and spend a lot of time learning how systems behave under scale and pressure.
